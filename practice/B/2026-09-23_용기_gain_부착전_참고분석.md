# 용기 gain 부착 전 참고 분석

## 결론

이 분석은 workbench 용기 계량 경로의 과거 데이터를 정리한 것이다. 측정 당시에는 그리퍼의 PLA 부착물로 바꾸기 전이었고, 철회된 공구 설정 `cz=89`를 사용했다. 따라서 아래 gain·offset은 현재 운영값으로 적용할 수 없다.

과거 측정 조건 안에서 가장 일관된 후보는 다음과 같다.

```text
보정값_g = raw_g × 1.222397 + 281.727171
raw_g = -Fz_N / 9.80665 × 1000
```

이 후보는 `gain_retry01.csv`의 79·129·179·229 g 네 하중점에 최소제곱 직선을 적합해 얻었다. 네 점의 최대 잔차는 1.576 g이다. 이 값은 과거 조건의 분석 후보이며 `common.yaml` 변경 근거가 아니다.

요약 통계는 [`g1_workbench_pre_attachment_summary.csv`](../../ros2_ws/src/gmp_dosing/calibration/g1_workbench_pre_attachment_summary.csv)에 기록했다. CSV의 로봇 측정값은 위 후보를 회차별 raw 평균에 사후 적용한 값이다.

## 측정 상황

- 위치와 자세: `workbench`, BASE z=180 mm, solution space 3
- 계량 경로: `get_tool_force(DR_BASE)`의 Fz를 `fz_sign=-1`로 환산
- 파지 조건: 용기를 한 번 잡은 상태에서 하중을 순차적으로 바꾸는 방식
- gain 하중: 79, 129, 179, 229 g
- 반복: 하중별 2회, 회차별 20표본, 표본 시작 간격 약 0.82초
- 별도 관찰: 79 g 고정하중 drift 20회와 65표본 고정하중 10회
- 영점 관찰: 측정 전후 빈 그리퍼를 각각 5회 측정

원시 파일은 로컬 `records/그리퍼 달기전이라 참고용/` 아래에 있다.

- `workbench_cal_Sd6jBKcK/gain.csv`
- `workbench_cal_Sd6jBKcK/gain_retry01.csv`
- `workbench_cal_Sd6jBKcK/drift.csv`
- `workbench_cal_Sd6jBKcK/zero_before.csv`
- `workbench_cal_Sd6jBKcK/zero_after.csv`
- `oscillation_test_My2eENHl/fixed79_s65.csv`

측정 뒤 공구 조건이 1.36 kg·CoG `[5.31, -34.68, 8.28]` mm의 PLA 조건으로 동결되었다. `cz=89`는 실제 무게중심이 아니라 모멘트를 상쇄한 보정항이었다는 이유로 철회됐다. 이 때문에 이 분석은 현재 공구 조건의 보정을 대신하지 않는다.

## 통계 계산 기준

한 회차의 로봇 측정값은 그 회차 표본들의 raw 평균에 선택 후보 `gain=1.222397`, `offset_g=281.727171`을 적용해 계산했다.

- 평균·중앙값·최솟값·최댓값: 회차별 로봇 측정값을 집계
- 평균오차: `평균 로봇 측정값 - 실제 무게`
- 중앙값오차: `중앙값 로봇 측정값 - 실제 무게`
- 평균절대오차: 회차별 `|로봇 측정값 - 실제 무게|`의 평균
- 평균절대오차율: `평균절대오차 / 실제 무게 × 100`; 실제 무게가 0 g이면 계산하지 않음
- 반복표준편차: 회차별 로봇 측정값의 표본표준편차

## 드리프트 분석

드리프트는 gain 적합과 분리해 해석해야 한다. `drift.csv`는 79 g을 한 파지로 유지한 채 약 17.877분 동안 20회 측정했다.

| 항목 | 결과 |
|---|---:|
| 선형 기울기 | +0.5231 raw g/min |
| 선택 gain 적용 시 기울기 | +0.6394 g/min |
| 선형 추세 제거 후 회차평균 σ | 3.302 raw g |
| 선택 gain 적용 시 추세 제거 σ | 4.037 g |
| 빈 그리퍼 raw 기준값, 측정 전 | -332.987 g |
| 빈 그리퍼 raw 기준값, 측정 후 | -288.005 g |
| 빈 그리퍼 전후 차이 | +44.982 raw g |

전후 영점 차이 44.982 raw g 전부를 시간 drift로 단정할 수는 없다. 두 영점 측정 사이에는 하중 변경과 사람 조작이 있었기 때문이다. 반면 `drift.csv`의 +0.5231 raw g/min은 같은 파지와 같은 79 g 하중에서 얻었으므로 시간에 따른 이동을 직접 보여준다.

이 결과는 offset이 세션 동안 고정되지 않았음을 뜻한다. 따라서 서로 다른 시각이나 다른 파지에서 얻은 하중점을 섞으면 영점 이동이 기울기에 들어가 gain을 오염시킬 수 있다.

## 핵심 해석

`gain_retry01.csv`의 네 하중점에 최소제곱 직선을 적합한 결과는 다음과 같다.

```ini
gain      = 1.222397
offset_g  = 281.727171
최대 잔차 = 1.576 g
```

후보 적용 후 하중점별 평균오차는 다음과 같다.

| 실제 하중 | 평균오차 |
|---:|---:|
| 79 g | -1.482 g |
| 129 g | +1.576 g |
| 179 g | +1.480 g |
| 229 g | -1.574 g |

네 하중점 모두 평균오차 절댓값이 약 1.6 g 이내였다.

## gain·offset 후보

보정식은 `실제 무게 = gain × raw_g + offset_g`로 두었다.

| 근거 | gain | offset_g | 최대 잔차_g | 판단 |
|---|---:|---:|---:|---|
| `gain.csv` 4점 전체 | 1.123905 | 268.419924 | 13.411 | 179 g 오염으로 폐기 |
| `gain_retry01.csv` 4점 전체 | 1.222397 | 281.727171 | 1.576 | 과거 조건의 선택 후보 |
| retry 79↔129 g | 1.151948 | 271.440059 | 0 | 두 점이라 직선성 검증 불가 |
| retry 79↔179 g | 1.187234 | 277.334759 | 0 | 두 점이라 직선성 검증 불가 |
| retry 79↔229 g | 1.223152 | 283.335071 | 0 | 전체 범위를 쓰지만 중간점 검증 없음 |
| retry 129↔229 g | 1.262160 | 285.067892 | 0 | 선택한 시작점에 민감 |

두 점 후보의 잔차가 0인 것은 두 점이면 직선이 항상 두 점을 정확히 통과하기 때문이다. 잔차 0을 정확도 증거로 사용하지 않는다.

## 후보 선정 이유

과거 조건의 대표 후보로 다음 값을 선정했습니다.

```ini
gain     = 1.222397
offset_g = 281.727171
```

선정 이유는 다음과 같습니다.

1. 79·129·179·229 g 네 점을 모두 사용해 두 점 후보보다 직선성을 확인할 수 있습니다.
2. 최대 잔차가 1.576 g으로 첫 측정의 13.411 g보다 작습니다.
3. 네 하중점의 평균오차가 약 ±1.6 g 이내입니다.
4. 전체 범위를 사용하는 79↔229 g 두 점 gain `1.223152`와 0.06% 차이입니다.
5. 첫 측정에서 나타난 179 g 회차 오염이 재측정에서는 반복되지 않았습니다.

다만 하중별 반복이 2회뿐이고 같은 세션에서도 drift가 확인됐다. 이 후보는 과거 데이터 요약에만 사용한다. 현재 운영 gain·offset은 현재 공구 조건에서 한 파지 3점 측정을 완료한 뒤 별도로 확정한다.
