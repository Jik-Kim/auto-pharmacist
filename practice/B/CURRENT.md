
    ③ gain 불확실도 ≤ ±2 % ④ 스쿱 경로 1.0013 과 2 % 이내면 단일 gain, 밖이면 경로별 분리(구조 변경 → 조장 결재).

    2점이 아니라 3점인 이유: 9/23 은 79/229 두 점이라 **직선성을 못 봤다**. 하중 두 번 더 넣는 데 30초다.
