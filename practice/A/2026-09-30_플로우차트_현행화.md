# 플로우차트 현행화 (2026-09-30)

## 요청·범위
- 사용자 승인으로 현재 브랜치 `fix/return-material-periodic`의 `5bb067e` 구현·설정을 기준으로 저장소 공정/A 도면과 제공 HMI 도면을 갱신했다.
- `Control_Server.drawio`의 작업·판단·통신/필드 병기 방식을 참고했다. 그 파일의 AMR·토큰·비전 동작은 이식하지 않았다.
- 기존 4+3페이지를 유지했고 HMI 2페이지를 [HMI_DB_Flow.drawio](../../docs/diagrams/HMI_DB_Flow.drawio)로 추가했다. Downloads 원본은 보존했다.

## 변경
- 공정 생성기와 도면: 계약 v1.11, RunBatch·예약, 직접 안전 요청, RestoreGrip, 반환/QA 분기·폐기 safe 경유·넛지 후 SafePose 반영.
- A: 폐기된 부분 붓기·매 원료 용기 계량을 스쿱 계량·전량 붓기·추정 누적으로 교체. 관련 상자·연결선만 삭제/대체하고 안전 이탈·소프트웨어 정지/복구 경로 추가.
- HMI: RunBatch 미구현·회수 확인 API 등 이전 설명 제거, 진행/예약 Goal 분리·직접 A 안전 요청·미측정 기록 의미 갱신.
- 공정 4페이지의 행 수보다 짧은 레인·겹치는 하단 설명 위치를 정정했다.
- 현행 `tare_agree_g=0`은 1회 계량이다. 코드의 선택적 2~3회 기준 확인을 현재 운영으로 잘못 쓰지 않도록 구분했다.

## 검증
- 3개 drawio, 총 9페이지 XML 파싱·ID 중복·연결 대상 검사.
- 생성기 Python 구문 검사 및 `python3 tools/make_process_drawio.py` 재실행 후 바이트 동일성 확인.
- 코드 분기·설정·HMI 요청 방향을 읽기 대조하고 XML 좌표 기반 로컬 미리보기로 상자 문구 넘침을 확인했다.
- diagrams.net 고유 렌더러는 사용하지 않았다. 미리보기는 구조 확인용으로 자동 연결선·HTML 글꼴의 완전 동일 렌더링을 보증하지 않는다.
- 실행 코드·ROS 계약·운영 설정 변경 없음. 로봇 실행·전체 빌드·실물 시험은 수행하지 않았다.
