## 검증과 한계

- 번들 통합 시 7개 패키지 빌드 성공. 기존 공정 테스트 실패 5건과 HMI의 옛 WEIGH_RESIDUAL 표시 불일치 1건은 남아 있다.
- 반환 수납 전체 스킬 시험은 563개 통과·취소 시험 기대값 1개 실패 후, 취소가 예외로 종료되는 실제 동작에 맞게 시험을 정정했다. 수정한 파일의 55개 시험은 전부 통과했다. Python 문법·diff 검사도 통과했다. 실물은 아직 움직이지 않았다.
- 자동 공정 CLEANUP은 반환 뒤 material 이동을 별도로 요청하므로 새 수납의 반환 끝 관절 검사와 충돌한다. C 후속 연결 대상으로 남긴다. 수납 없이 즉시 재스쿠핑하는 자동 초과 반환 경로도 계속 차단된다.

- C 담당 문서는 읽기 전용 유지. 임시 담당 표시 없음. 사용자 요청에 따라 이후 코드 변경은 검증 후 로컬 커밋까지 수행한다. push는 별도 요청 때 한다.
