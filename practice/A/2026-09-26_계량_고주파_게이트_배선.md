# 2026-09-26 계량 고주파 게이트 배선

## 배경

- GitHub Issue [#208](https://github.com/Jik-Kim/auto-pharmacist/issues/208): `fit_oscillation()`과 `max_hf_std_g`가 구현돼 있었지만 운영 계량 호출부가 원시 표본을 버려 두 경로 모두 꺼져 있었다.

## 변경

- `DsrArm.measure_force()`와 `measure_workpiece()`에 기존 반환 형식을 유지하는 `include_samples` 옵션을 추가했다.
- `skill_node._measure_weight_reading()`이 원시 표본을 `fit_oscillation()`에 넣고, 적합 평균·잔차 σ·고주파 σ를 `WeightModel.reading()`에 전달하게 했다.
- 빈 스쿠 접촉 기준선은 적합 값이 아닌 장치 원본 평균·σ를 계속 저장하게 분리했다.
- `common.yaml`과 `process_node` 파라미터에 `scale.max_hf_std_g=9.5` 를 등록했다.

## 검증

- `gmp_skills`: 490 passed.
- `gmp_skills + gmp_process`: 634 passed / 2 skipped / 1 xfailed.
- 실물 로봇 계량은 수행하지 않았다. 현 `9.5 g`은 B 실측 기반 기존 기본값이며, 운영 적합 후 다시 검증해야 한다.
