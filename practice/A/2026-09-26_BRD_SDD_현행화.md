# BRD·SDD v1.0 현행화

## 목적

GitHub Issue #151의 BRD v1.0을 현행 계약·결정과 맞추고, 구현 기준 SDD v1.0을 작성했다.

## 확인한 원본

- `PROJECT_RULES.md`
- `docs/SOT.md` D-26·D-27·D-32·D-33
- `docs/interfaces.md` 계약 v1.8
- `ros2_ws/src/gmp_process/gmp_process/core/process_fsm.py`
- `ros2_ws/src/gmp_bringup/params/common.yaml`
- `ros2_ws/src/gmp_bringup/params/stations.yaml`
- `ros2_ws/src/gmp_bringup/params/recipes/*.yaml`

## 반영

- BRD의 현행 요구사항을 85 g 스쿱, 85/170 g 단위 레시피, ±10%, 고정 스쿱, DIO 기본 그리퍼, 계약 v1.8로 정정했다.
- 과거 개정 이력은 당시 기록으로 보존했다.
- SDD에 패키지 책임, 단일 워커, FSM, 이동·계량·안전·기록·검증 설계를 연결했다.

## 남은 실물 검증

힘 계량 정확도, 실제 파지력, 미끄럼, 충돌 감도와 안전 스위치는 문서 작성으로 완료 처리하지 않는다.
