# 레시피 2·3 B 목표량 변경

기록: 2026-09-29 17:46 KST. 사용자 요청으로 운영 레시피 2·3의 B 목표량을 57→69 g으로 바꿨다. 원료 B 스쿱 1회량도 현재 69 g이라는 사용자 정정에 따라 운영 도징 설정·HMI 통신 시험 설정을 맞췄다.

레시피 1은 기존 A/B/C 69 g·±15 %를 유지한다. 레시피 2·3의 허용오차 ±10 %도 유지한다. 시험 레시피 사본, 카탈로그 검증기, 데모 데이터와 현행 문서의 값을 동기화했다. [운영 레시피](../../ros2_ws/src/gmp_bringup/params/recipes), [시험 레시피](../../ros2_ws/src/gmp_hmi/config/test_recipes/v4), [SOT](../../docs/SOT.md)

운영·시험 레시피 대조를 포함한 관련 단위 테스트 117개가 통과했다. JavaScript 문법과 Python 문법도 확인했다. 실제 ROS 통신 시험과 실물 분주는 실행하지 않았다.
