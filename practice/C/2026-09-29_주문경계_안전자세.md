# 주문 시작·넛지 후 안전 자세 연결

- 사용자 지시로 C 코드를 수정했습니다. SELF_CHECK 시작 요청을 SafePose로 바꾸고, 성공 후 RestoreGrip(expected_payload=empty) 및 외력 자가진단을 거쳐 빈 통 파지로 진행합니다.
- 넛지 후 SET_COMPLETE SafePose가 성공해야 DONE이 됩니다. 복귀 실패는 ERROR이며 새 주문의 정상 연속 시작으로 처리하지 않습니다.
- FSM·RunBatch·인터락 관련 기존 및 변경 시험 133건 통과. 이후 시작 서비스 순서·실패 차단 3건을 추가해 해당 인터락 파일 12건 통과했습니다.
- 실물 주문은 미시작입니다. 사용자가 2·3번 원료통이 비어 있다고 알려 정상 레시피 완주/조제 생략 이송 시험 중 범위를 확인 중입니다.
- 실행 ROS 조회: process_node·skill_node 존재, mode=IDLE이지만 기존 인터락 ENTER 대기가 남아 있습니다. 재시작으로 인터락을 우회하지 않고 현장 퇴장 및 EXIT 처리가 필요합니다.
