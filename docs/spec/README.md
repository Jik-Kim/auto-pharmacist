## 규칙

- 여기가 원본이다. 노션은 사본. **버전마다 새 파일**, 내용이 바뀌면 minor 를 올리고 문서 안 변경 이력에 한 줄.
- 요구사항의 근거는 **규정**이다 — 칭량 정확도(약전 허용 오차), 배치 기록(법적 의무), QA 이중 확인(GMP), 교차오염 방지(원료별 전용 스쿱), 펜스리스(청정실 기류·청소). 각 FR 에 근거 칸을 둔다. 근거가 없는 요구사항은 넣지 않는다.
- SDD 5장(상세 설계)의 상태 전이표는 `gmp_process/core/process_fsm.py` 와 **같은 것**이어야 한다. 코드가 바뀌면 표도 바뀐다.
