# **1. 비즈니스 목표**

두산 협동로봇 M0609(6축, 가반하중 6 kg, 최대 도달거리 900 mm)와 OnRobot RG2 그리퍼를 이용하여, 배치 레시피(원료 3종·목표량·허용 오차)에 따라 원료를 전용 스쿱으로 퍼서 칭량 용기에 분주하고, 로봇 관절 토크 기반 외력(작업물 무게 추정)만으로 순량을 재어 허용 오차를 스스로 검증하며, 과다 투입 등 되돌릴 수 없는 일탈이 생기면 셀 밖의 QA 담당자에게 웹 HMI 로 원격 판정을 요청하고, 모든 계량값·판정·사람 조작을 배치 기록(SQLite, 감사 추적)으로 남기는 무인 조제 칭량 셀을 구현한다. 카메라·외부 저울·외부 센서는 쓰지 않는다. 평상시 셀은 무인이며, 사람은 패스박스(물자)와 HMI(판정·지시)로만 셀과 만난다. 이를 통해 사람 칭량의 오차와 오염 요인을 제거하고, 배치 기록서 수기 작성을 대체하며, 일탈이 나도 사람이 셀에 들어가지 않는 공정 지속성을 확보한다.

**시장 배경.** 전 세계 약국 자동화 시장은 2025년 15억 달러에서 2034년 41억 달러로 성장(CAGR 11.81 %)할 것으로 전망되며, 성장 동인은 처방 정확성·작업 흐름 효율·재고 가시성·환자 안전, 그리고 노동력 부족과 처방량 증가다. 로봇 조제 장치·자동 포장·약물 보관·통합 소프트웨어가 주요 제품군이고, 약물 추적성과 규정 준수가 자동화 수요를 형성한다. 본 프로젝트는 이 중 "로봇 조제 장치" 의 상류 공정인 원료 칭량·분주를 축소 실증한다. 시장이 요구하는 처방 정확성·추적성·규정 준수가 그대로 본 시스템의 칭량 정확도·배치 기록·QA 이중 확인에 대응한다.
(출처: Fortune Business Insights, 약국 자동화 시장 보고서 요약 페이지(한국어), <https://www.fortunebusinessinsights.com/ko/pharmacy-automation-market-116176>, 조회 2026-09-17)

**교육·평가 관점.** 본 과제는 ROS 2 기반 로봇 자동화 공정 시스템(R1)이며, 비전 미사용(R2)·사람 개입 최소화(R3)·추가 장비 없음(R10) 조건에서 강사 지정 매뉴얼 4개 절(3 모션·4 제어 보조·5 기타 설정·6 힘/순응·사용자 편의, R24)의 명령을 실제 공정에 사용한다. 평가 항목 중 「기능 동작 지속성」(일탈 자동 복구)과 「입출력 데이터 이해도」(배치 기록 HMI)가 본 설계의 중심이다(R12).

# **2. 프로젝트 범위**

M0609 로봇팔이 사람이 매거진에 넣어 둔 빈 약통을 칭량 위치로 반송하고, 풍량(tare)을 잰 뒤, 원료마다 전용 스쿱을 집어 원료통에 힘제어로 담가 퍼올리고, 칭량 용기에 부은 뒤 다시 재어 목표량에 도달할 때까지 보정 투입하는 이중 폐루프 공정을 개발·적용한다. 원료 3종이 모두 허용 오차 안이면 완료품을 용기째 트레이로 옮기고 배치 기록을 마감한다. 주요 기능에는 레시피 검증·실행 상태기계, 스테이션 이동·파지·스쿱·붓기·계량 스킬, 힘→그램 환산·영점·도징 정책, 일탈 정책표(재시도·보충·QA·강제 개입)와 인터락, 웹 HMI(주문·상태·원격 QA 판정·인터락·이력) 및 SQLite 배치 기록이 포함된다. 실물 작업 가용일은 9/17·18·21·22·23 의 5일이며(R11), 9/29 시연·9/30 발표다.

## **포함 범위 (In Scope)**

* M0609 툴 무게(1.320 kg)·무게중심 등록 및 기동 시 툴·TCP·충돌 감도 자가진단 (R7)

* 스테이션 9곳(칭량·원료통 1~4·스쿱랙·매거진·완료품 트레이·폐기함·패스박스·안전 자세) 티칭 좌표의 단일 출처(`stations.yaml`)와 판 좌표계 (D-09·D-15)

* 빈 약통 반송(매거진 → 칭량 위치), 완료품 반송(→ 트레이 같은 슬롯), 폐기 반송(→ 폐기함) — 매거진 3슬롯 낱개 (D-18)

* 원료별 전용 스쿱 픽업·반납 (교차오염 방지), 정지 폭 추론에 의한 파지 판정 (D-05)

* Z 방향 힘/순응 제어(task_compliance_ctrl, set_desired_force, check_force_condition)로 원료면 접촉을 감지하며 퍼올리기, 담금 깊이 상한

* 붓기(movel/movesx) 및 보정 투입 시 amove_periodic 털어내기, 퍼낸 양 고르기(move_periodic)

* 로봇 외력 계량 — get_workpiece_weight 1순위, get_tool_force 폴백, 영점(reset_workpiece_weight)·보정 계수·표준편차·유효 판정 (D-07). 로봇이 저울이므로 **스쿱을 든 채** 빈 스쿱·붓기 전·붓기 후 세 번 재고, 용기는 배치 끝에 한 번 들어 잰다 (D-22)

* 이중 폐루프 도징 정책 — 붓기 전 스쿱 계량으로 붓기 비율 결정(1차, 초과 예방), 붓기 후 잔량으로 실제 투입량 누적(2차) — OK / UNDER(다시 퍼서 보정, 최대 3회) / OVER(일탈) / TIMEOUT. 배치 끝 용기 계량으로 누적값 대조

* 일탈 정책표 9종(파지 실패·미끄러짐·스쿱 빈 채·원료 소진·과다 투입·계량 무효·시간 초과·안전 스위치·힘 상한)과 자동 복구·보충 인터락·QA 판정·강제 개입 분류

* 사람 투입 인터락(ENTER 는 안전 자세 도달 후 허가, EXIT 로 재개) 및 두산 충돌 감지(PFL)

* 웹 HMI(Flask) — 주문 제출, 상태·그리퍼 폭·계량 그래프, 셀 밖 기기에서 QA 승인/폐기, 인터락, 이력·KPI·감사 추적 조회 (D-16)

* 배치 기록 — record_node 단일 기록자, SQLite 6 테이블, events append-only, 배치 종료 시 JSON 사본 (D-17)

* 강사 채택 추가 기능 — ① 폭 지문 식별(다른 스쿱·용기 → WRONG_TOOL) ③ 재기동 이어하기(DB 상태로 중단 지점 재개) ⑤ 원료 잔량 추정·보충 권고 ⑦ 사람 접촉 반응(건드리면 정지, 다시 건드리면 재개) (R27, D-21)

* 가상 모드(에뮬레이터)와 실물 모드를 같은 런치·파라미터로 실행

# **3. 기능 요구사항 (Functional Requirements)**

우선순위: **필수** = 9/29 시연 수락 조건, **권장** = 시간이 허락하면.

| :---: | ----- | :---: |
| 3.1.1 | 시스템은 레시피(제품명, 원료 목록 — 원료 ID·목표량 g·허용 오차 %·등급·전용 스쿱)를 yaml 로 받아 검증(필수 필드, 원료 중복, 양수, 원료 수 ≤ 4)한 뒤 주문으로 접수해야 한다. 잘못된 주문은 사유와 함께 거부한다. | 필수 |

| 3.1.5 | 등급(ACTIVE 주성분 / EXCIPIENT 부형제)별 기본 허용 오차를 레시피 yaml 에서 정의할 수 있어야 한다. | 권장 |

## **3.2 용기·도구 취급 (Container & Tool Handling)**

| 번호 | 요구사항 설명 | 우선순위 |
| :---: | ----- | :---: |
| 3.2.1 | 로봇은 사람이 매거진 슬롯(3개, 낱개)에 넣어 둔 빈 약통을 파지해 칭량 위치로 반송해야 한다. | 필수 |
| 3.2.2 | 파지 성공은 그리퍼 정지 폭으로 추론해야 한다 — 정지 폭이 목표 폭 + 마진(2 mm)보다 크면 파지, 목표 폭까지 닫혔으면 실패. | 필수 |
| 3.2.3 | 원료마다 전용 스쿱을 스쿱랙에서 집어 쓰고, 원료 전환 시 같은 슬롯에 반납해야 한다 (교차오염 방지). | 필수 |
| 3.2.4 | 완료된 배치는 용기째 완료품 트레이의 같은 슬롯 번호로, 폐기 판정은 용기째 폐기함으로 반송해야 한다. | 필수 |
| 3.2.5 | 파지 중 폭 변화가 미끄러짐 임계(1.5 mm)를 넘으면 미끄러짐으로 감지하고 재파지해야 한다. | 권장 |
| 3.2.6 | 스쿱·용기의 파지 정지 폭이 기대 규격 ± 마진 밖이면 도구 불일치(WRONG_TOOL) 일탈을 발생시켜야 한다. (추가 기능 1) | 권장 |

## **3.3 퍼올리기·투입 (Scoop & Pour)**

| 번호 | 요구사항 설명 | 우선순위 |
| :---: | ----- | :---: |
| 3.3.1 | 스쿱을 든 로봇은 순응 제어에 진입해 Z 방향 목표 힘으로 원료통에 하강하고, check_force_condition 으로 원료면 접촉을 감지해야 한다. | 필수 |
| 3.3.2 | 담금 깊이는 상한(`dip_max_mm`)을 넘지 않아야 하며, 순응 제어는 진입·해제를 반드시 짝으로 수행해야 한다. | 필수 |
| 3.3.3 | 퍼올린 뒤 들어 올린 상태에서 move_periodic 으로 퍼낸 양을 고르게 한 후 칭량 용기 위로 이동해야 한다. | 권장 |
| 3.3.4 | 칭량 용기 위에서 기울여 붓되, 보정 투입(비율 < 1)에서는 amove_periodic 털어내기로 소량씩 투입해야 한다. | 필수 |
| 3.3.5 | 접촉이 감지되지 않으면 스쿱 빈 채(SCOOP_EMPTY)로 재시도하고, 연속 3회면 원료 소진(MATERIAL_EMPTY)으로 판정해야 한다. | 필수 |

## **3.4 계량·도징 (Weighing & Dosing)**

| 번호 | 요구사항 설명 | 우선순위 |
| :---: | ----- | :---: |
| 3.4.1 | 무게는 로봇이 물체를 든 상태에서 고정된 계량 자세로 get_workpiece_weight 를 N회(기본 20) 읽어 평균·표준편차로 구하고, 영점은 빈 그리퍼로 같은 자세에서 reset_workpiece_weight 로 잡아야 한다. | 필수 |
| 3.4.2 | 빈 용기 풍량(tare)은 배치 시작 시 용기를 들어 재고, 빈 스쿱 풍량은 원료마다 스쿱을 집은 직후 든 채로 재야 한다. | 필수 |
| 3.4.3 | 퍼올린 뒤 붓기 전에 스쿱을 든 채 재어 퍼낸 양을 구하고, 퍼낸 양이 부족량보다 많으면 부족량만큼만 붓도록 붓기 비율을 정해야 한다 (1차 폐루프 — 초과 예방). | 필수 |
| 3.4.4 | 붓고 난 뒤 스쿱을 다시 재어 잔량을 구하고, 붓기 전후 차이를 실제 투입량으로 누적해야 한다. 스쿱에 남은 원료는 투입량으로 세지 않는다. | 필수 |
| 3.4.5 | 정착 실패·힘 조회 실패 등 유효하지 않은 계량(`valid=false`)은 값을 쓰지 않고 재계량(2회)하며, 계속 무효면 일탈로 QA 판정을 받아야 한다. | 필수 |
| 3.4.6 | 오차율 = (누적 투입량 − 목표) / 목표 × 100. \|오차율\| ≤ 허용 오차면 OK, 미달이면 UNDER 로 다시 퍼서 보정 투입(최대 3회), 초과면 OVER 로 일탈 처리해야 한다. | 필수 |
| 3.4.7 | 초과 투입은 되돌리지 않는다 — 회수 동작을 만들지 않는다. | 필수 |
| 3.4.8 | 원료가 모두 끝나면 용기를 들어 순량을 재어 스쿱 누적 투입량과 대조하고, 차이가 분해능을 넘으면 불일치(VERIFY_MISMATCH) 일탈로 QA 판정을 받아야 한다 (2차 검증). | 필수 |

# **4. 비기능 요구사항 (Non-Functional Requirements)**

## **4.1 신뢰성**

* 일탈이 발생해도 사람이 셀에 들어가지 않고 공정이 이어져야 한다. 일탈 자동 복구율 90 % 이상, 매거진 3슬롯 연속 배치 사람 개입 0회를 목표로 한다.

* 강제 개입 사이 평균 시간(MTBI)을 대표 지표로 측정·보고한다. QA 원격 승인과 원료 보충 인터락은 규정 절차이므로 개입으로 세지 않는다.

* 상태 전이·일탈·오류는 100 % 기록되어야 하며, 재기동 후 중단 지점부터 재개할 수 있어야 한다.

## **4.2 안전성**

* 사람·구조물과의 의도치 않은 접촉 사고 0건. 인터락 없이 사람이 셀 안에 손을 넣지 않는다.

* 안전은 기구적 분리(사람 구역 = 로봇 도달 밖) → 인터락(안전 자세 후 허가) → 두산 충돌 감지(PFL, ISO/TS 15066) 3층으로 성립하며, 하드웨어 안전 기능을 소프트웨어로 대체하지 않는다.

* 안전 정지는 process·hmi·record 노드와 독립이어야 한다.

## **4.3 정확성·재현성**

* 각 원료의 실측 순량이 허용 오차 안(OK 판정)이어야 하며, 도징 단위와 허용 오차는 9/17 실측 분해능(3σ)에서 유도한다 — 30 g 을 가르면 30 g 단위, 아니면 100 g 단위·±5 %.

* 계량 자세를 하나로 고정하고 영점을 같은 자세에서 잡아 중력 성분 편차를 제거한다.

* 같은 레시피를 반복할 때 같은 판정이 나와야 한다 (배치 5회 중 4회 이상 DONE 목표).

## **4.4 성능**

* 사람 접촉(nudge) 감지부터 정지까지 1 s 이내, QA 판정 반영부터 로봇 재개까지 2 s 이내를 목표로 한다.

* 공정 상태는 2 Hz + 변화 시 발행, 그리퍼 상태는 10 Hz 발행.

* 사이클타임(주문 수락 → 완료)은 측정·보고한다 (Phase 1 목표값 없음).

## **4.5 유지보수성·확장성**

* 힘→그램 환산·도징 정책·상태기계·레시피 검증은 ROS 비의존 순수 함수로 두어 로봇 없이 pytest 로 검증한다.

* 좌표·임계값·레시피는 yaml 이 단일 출처이며 코드에 상수를 두지 않는다. 스테이션 ID 는 문자열이라 스테이션이 늘어도 재빌드가 없다.

* 벤더 패키지(doosan-robot2, onrobot-ros2)는 수정하지 않고 언더레이로 둔다.

## **4.6 규정 준수**

* 요구사항은 GMP 원칙에서 유도한다 — 칭량 정확도(약전 허용 오차), 배치 기록 작성·보존, QA 이중 확인, 일탈 관리, 감사 추적(데이터 완전성), 교차오염 방지(원료별 전용 도구), 무균 구역 무인·펜스리스. 조항 번호는 발표 전 확인한다.

* 협동로봇 안전은 ISO 10218 / ISO/TS 15066(PFL)을 따른다.

# **7. 수락 기준 (Acceptance Criteria)**

* 레시피 1건(원료 3종)을 사람 손 없이 완주(DONE)하고, 각 원료가 보정 투입 3회 안에 OK 판정을 받아야 한다 (배치 5회 중 4회 이상).

* 약통 3개를 매거진에 두고 연속 3배치가 사람 개입 없이 완료되어야 한다.

* 고의 장애 3종 — (a) 스쿱 제거 → GRIP_FAIL 자동 재시도, (b) 원료통 비움 → MATERIAL_EMPTY → 인터락 보충 → 재개, (c) 과다 투입 → OVERFILL → 셀 밖 기기에서 QA 승인/폐기 — 가 각각 재현되고 일탈이 기록되어야 한다 (각 3회).

* 계량 유효 판정과 재계량이 동작하고, 참조 저울 대조 오차가 실측 분해능 이내여야 한다 (10회).

* 붓기 전 스쿱 계량으로 붓기 비율이 조정되어 과다 투입이 예방되고, 스쿱 잔량이 투입량에서 제외되며, 배치 끝 용기 계량이 스쿱 누적값과 분해능 이내로 일치해야 한다 (5배치).

* 인터락 ENTER 는 로봇이 안전 자세에 도달한 뒤에만 허가되어야 하며, 전 시험에서 접촉 사고 0건이어야 한다.

* 계량 대기·인터락 중 로봇을 건드리면 1 s 이내에 정지하고 다시 건드리면 재개해야 하며, 접촉 없는 배치에서 오검출이 없어야 한다 (10회).

* 툴·TCP·충돌 감도 불일치를 주입하면 기동이 거부되어야 한다.

* DB 의 계량·분주·일탈·이벤트 행 수가 시험 기록지와 100 % 일치하고, 사람 조작 전부에 판정자/작업자 ID 가 있으며, 배치 JSON 이 생성되어야 한다.

* 추가 기능 — 다른 스쿱을 두면 WRONG_TOOL 이 검출되고(5회), 실행 중 종료 후 재실행하면 중단 지점부터 재개되며(3회), HMI 에 잔량 게이지가 표시되어야 한다.

* 강사 지정 매뉴얼 4개 절(3·4·5·6)의 명령이 실제 스킬 코드에 있고 시연에서 실행되어야 한다.
